# MAPA · pessoas

Uma ficha por pessoa com quem {PESSOA} trabalha de verdade.

## Objetivo

Lembrar como cada pessoa trabalha, o que ela decide e o que ela precisa receber pronto — para eu não te fazer reexplicar isso toda vez.

## Quando usar

Pessoa recorrente no seu trabalho: quem aprova, quem depende de você, quem você depende, quem é fonte de um assunto.

## Quando NÃO usar

Contato de uma vez só. E **nunca** para registrar julgamento de desempenho — ver Sensibilidade.

## Sensibilidade

🔴 **ALTA. Esta pasta nunca vai para o cérebro coletivo da Bravo.** É o gatilho 2 por definição.

Mesmo aqui, dentro do seu cérebro privado, o critério é: **registrar como a pessoa trabalha, não julgar se ela é boa.** "Prefere receber número antes da reunião" é como trabalha. "É desorganizada" é julgamento — não escrever.

A diferença importa porque este arquivo vive num repositório, e repositório guarda histórico. O que você escreve hoje continua legível daqui a dois anos.

## Formato

```markdown
# {Nome}

- **Papel:** {cargo e área}
- **Como se relaciona com meu trabalho:** {depende de mim / eu dependo / aprova / é fonte}
- **Como prefere receber as coisas:** {formato, antecedência, nível de detalhe}
- **O que ela decide:** {a alçada real dela}
- **Assuntos que passam por ela:** {temas}
- **Combinados que já temos:** {o que já foi acordado entre vocês}
```
